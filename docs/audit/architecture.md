# Architecture and backend audit
Scope: orchestrator, workflow, runner, worktrees, github, release, mcp_server, models. No fix in this PR. Sorted by severity. Effort: S < 1 day, M 1-3 days, L > 3 days.

## Critical
C1. Throttled chatter wakeups are dropped, not deferred. dispatcher.py:292 + :369-414; SkipRun -> _finish marks wakeups finished (:171-172). A mention arriving while a conversation is over max_runs_per_conversation_hour (config.py:74) is lost forever; agents are never woken. Fix: on throttle, leave chatter wakeups queued (started_at=None, add not_before column) and coalesce them into one run when the window frees; never finish a mention unrun. Also count per employee, not per conversation (13 agents in one channel hit the cap fast). Effort M.
C2. Release ships commits missing from CHANGELOG. projects.py:403-404 (already-bumped short-circuit) + :459/:476 (merge pinned to PR head). Tasks merged on the team branch after the chore(release) commit are in the release PR head but not in the CHANGELOG entry; if they don't change the SemVer level, nothing is recomputed. Fix: on each merge_release call, recompute the entry from commits since the last tag and recommit when it differs (idempotent entry), or refuse the merge when commits exist after the last chore(release) commit. Effort S/M.

## High
H1. Pure rebases restart the full review cycle. workflow.py:390-392 (round+1 at every submit), :496 (approvals scoped to the round), merge_watch.py:102-103/:116 (dirty PR -> changes_requested). Every merge on dev can send other PRs back, the rebase resets approvals, reviewer/QA/security are woken again (#137, #138). Fix: store the reviewed patch-id (git patch-id of merge-base..head) on the task; on submit, if unchanged keep the round and approvals, only wait for CI; refuse a submit from changes_requested with no new commit and identical patch. Effort M.
H2. Project deletion leaves files silently. worktrees.py:32-39 rmtree(ignore_errors=True): agent-owned files (agent_user) are not removable by the backend; Claude session dirs too. Fix: reuse _remove_clone (sudo rm-clone pass) per clone, then raise/log what is left. Effort S.
H3. rm-clone.sh hardcodes /data/projects. scripts/rm-clone.sh:12 while projects_dir is configurable (config.py:38): with another PROJECTS_DIR the sudo pass always fails -> CloneRemovalError, desks cannot be recreated. Fix: install the script with the prefix substituted at install time (entrypoint), or a check at startup that settings.projects_dir == the script prefix. Effort S.
H4. DB session held during git network operations. dispatcher.py:154-181 (phase 1 "short DB session") calls _refresh_repo/prepare_worktree/prepare_desk (clone, fetch) inside it: pool connections held for seconds/minutes, the project repo lock serializes them. Fix: do git prep outside the session, reopen one to persist task.branch/status. Effort S.
H5. Schema migrations are ad hoc. db.py:24-42: only nullable/text-default ADD COLUMN, plus a hardcoded agent_sessions special case (:38-40). No rename, drop, type change, index, backfill. Fix: a minimal versioned migrations table (ordered SQL functions in a migrations.py), no new dependency. Effort M.

## Medium
M1. Desk re-cloned at every conversation run. worktrees.py:254-267 (rm + clone --dissociate each time). IO and latency on each wakeup, multiplied by team size. Fix: keep the desk, reset it only when the run actually used Bash/Write (or once per N runs); security constraint on filters must be kept -> recreate only when dirty. Effort M.
M2. Token cost of wakeups. Each chatter wakeup resumes a session and re-sends the full system prompt (dispatcher.py:258-266); broadcast events wake every role listed in wakes_on (events.py:31). Fix: measure tokens per event type (AgentRun has the data), cut broadcast wakes_on, batch idle/daily, cheaper model for scribe/chatter. Effort M.
M3. Unbounded tables without indexes on hot queries. agent_runs has no index on (conversation_id, started_at) though _check_rate queries it every chatter run (dispatcher.py:395-404); rate_limit_lifted lookup scans events by JSON payload (:388-392); events/wakeups/agent_runs never purged. Fix: composite index, a column instead of JSON lookup, a retention job. Effort S.
M4. Merge not pinned to the reviewed SHA. workflow.py:585 merges without sha while merge_release pins it (projects.py:476). Fix: record reviewed head SHA, pass sha= to merge_pull_request. Effort S.
M5. In-memory state lost on restart. workflow.py:37 (_lead_pending), dispatcher.py:57 (_throttled_at), merge_watch.py:19-25, run_tokens.py:7-11. Acceptable today, but each one is a silent behavior change after a restart (duplicate CI announcements, lost lead updates). Fix: document it in one place; persist _lead_pending as events with a not_before. Effort S.
M6. N+1 queries in expand_events. events.py:73-87: per event, get(Task), conversation, room, members, all project employees. Fine at 200/batch, but runs every poll_interval_s (2 s). Fix: preload employees per project once per batch. Effort S.

## Low
L1. Duplicated task event set: events.py:14 TASK_EVENTS and workflow.py:29 TASK_EVENT_TYPES. Fix: one constant. S.
L2. Release helpers misplaced: VERSION_FILES/_lock_version/_package_name in projects.py:482-500 while release.py holds pure release functions; merge_watch.py:250 reaches into projects for it. Fix: move to release.py. S.
L3. Dead code: worktrees.py:275-276 git worktree prune "dead once none is left". Fix: remove. S.
L4. Small sync IO on the event loop: worktrees.py:23-29 (iterdir), :127-133 (resolve/write_text), runner.py:118-134. Negligible, but against the async rule. Fix: asyncio.to_thread. S.
L5. Fragile lookups: dispatcher.py:257 next() raises StopIteration if a name no longer matches the catalog team; :267 assign_accounts fallback recomputed. Fix: explicit error -> SkipRun. S.
L6. Typing: JSON columns typed loosely (models.py:325 payload dict, depends_on list without FK); event payload keys are stringly typed across modules. Fix: TypedDict per event type. M.
